# Maine Tabirao — Portfolio

A responsive, data-driven portfolio built with React, TypeScript, Vite, and custom CSS.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

## Deploy to Netlify

Push this project to GitHub and connect the repository to Netlify. Build command: `npm run build`. Publish directory: `dist`. A `netlify.toml` is included.

## Edit content

- `src/data.ts`: Profile URLs, skills, projects, project evidence, and development milestones.
- `src/styles.css`: Palette, typography, spacing, and responsive layout.
- `src/main.tsx`: React components, filters, workflow explorer, and case-study modal.
- `index.html`: Page title, description, and social metadata.

## Before publishing

1. Upload a verified, current resume if you want to offer a resume link; the site intentionally does not show a broken Resume button.
2. Add real screenshots, project URLs, and sanitized evidence only after verifying them.
3. Check all project claims, especially the unfinished BrightSmile automation.
4. Consider adding an original social-preview image and a custom domain.
5. The project illustrations are CSS-generated placeholders, not fake product screenshots.

## Privacy

Do not commit credentials, n8n secrets, patient details, or unredacted workflow exports.
